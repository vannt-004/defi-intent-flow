# DeFi Intent Flow

AI-assisted DeFi Portfolio Analytics and Simulation.

Tài liệu dự án chi tiết nằm tại:

- [docs/PROJECT_DOCUMENTATION.md](docs/PROJECT_DOCUMENTATION.md)

Tài liệu bao gồm:

- Kiến trúc backend/frontend.
- Luồng add wallet, queue worker, portfolio sync.
- Data model và MongoDB collections.
- Công thức net worth, PnL, cost basis, transaction history.
- Risk engine cho lending và LP.
- Simulation engine cho price shock, lend, borrow, swap, LP.
- Market ranking/AHP.
- Các công thức/giả định cần kiểm chứng.
